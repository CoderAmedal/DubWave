## Context
扩展的语音合成依赖本机 Python 服务，这在与商店「单一用途」「最小功能」条款相遇时是主要风险点。
同时仓库里混有开发资料（openspec/、docs/、helper/），不能直接整包上传。

## Decisions
### 打包与仓库分离
商店包只包含运行必需的四个路径，避免把 OpenSpec 记录、辅助脚本带进审核。

### 隐私政策放在仓库根目录
便于用 GitHub Pages / Raw 链接直接作为商店要求的公开 URL，且随代码一起演进。

### 先如实披露再优化体验
即使后续增加 `chrome.tts` 兜底，也保持「字幕文本会发送到翻译服务」的披露不变。

## Risks
- 若不加兜底，可能因「未启动 helper 即不可用」被判定功能不足
- 描述中出现平台商标可能触发商标审核
